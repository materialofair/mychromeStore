# SPACE AI 1.0.8 Implementation Plan

> **For agentic workers:** Use subagent-driven-development to implement the approved UI scope. Ownership is split between tool-card UI and extension integration/tests; both share existing runtime and storage contracts.

**Goal:** 把已确认的聊天侧栏与工具卡片方案落地为1.0.8，同时交付浏览器扩展实现指南和图表方案。

**Architecture:** 保留侧栏→manifest sandbox→工具srcdoc与Service Worker存储链路。只调整可信外框、侧栏局部样式、交互反馈和生成指导；原始源码、状态协议、权限和固定扩展身份不变。iframe继续作为.space-ai-ui直接子元素，放大不重建。

**Tech Stack:** 原生ES modules、CSS、Manifest V3、既有Vitest与Playwright，无新增依赖。
